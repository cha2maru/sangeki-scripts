# d27「病棟の恋人たちと委員長の契約」脚本家の指針

根拠: 脚本 `engine/scripts/designed/d27.json`（notes の pp・cs・wins）と、中身を知る Claude が脚本家を務めた7試合
（`selfplay/runs/claude_mm_d27_{intent,nulled,guard,defplan,defplan2,defplan3,look}_s51.jsonl`。6勝1敗、負けは readlook にループ4）。

## 負け筋（本命・控え）

1. **本命A: メインラバーズ（ML_PROT via C19）** — 学者の特性で**暗躍**を選んでおけば、残りは不安3。
   1日目に不安+1、2日目の不安拡大の不安2を学者へ置けば、2日目のターン終了フェイズで決まる。不安+1 だけなら3日かかる。
   （初版は「不安2」と書いていたが誤り。条件は暗躍1以上かつ不安3以上。Claude 同士の対戦の脚本家が指摘）
2. **本命B: 契約（Y_CONTRACT）** — 委員長に暗躍2。1日目の暗躍+2 が通ればそれで確定。通らなくても、主人公の暗躍禁止を1日目に吸わせる。
   2日目以降は不安拡大の暗躍1＋暗躍+1 で2に届く。

   A と B は**止める手が違う**（A は不安−1・ナース[2]・学者[3]、B は暗躍禁止）。不安拡大の2つの効果を
   **不安2→学者、暗躍1→委員長**と分けると、1回の事件で両方が1歩ずつ進み、主人公は1日で両方を止められない。
3. **控えC: 殺人事件（MURDER via C08、4日目）** — 医者に不安2。ナースを殺せば学者に不安6（A の完成）、学者を殺せばナースに不安6（6日目の病院の事件が確実）。
   ただしラバーズの連鎖が公開されて恋愛風景・ナースが割れるので、序盤のループでは3つ目の脅威（主人公の守りを割らせる）として見せるにとどめる。
4. **控えD: 不定因子χ（SUICIDE via C06、5日目）** — 都市に暗躍2＋サラリーマンに不安2。割れにくい筋なので**隠す**。最終ループ前に使うなら、
   契約で確定する前（キーパーソンの能力の持ち主が「殺人計画かファクター」と迷わせられるループ2〜3）に限る。
5. **控えE: 病院の事件（HOSPITAL_PROT via C17、6日目）** — ナースに不安3＋病院に暗躍2。病院に暗躍1でも病院の全員が死ぬ。最終日の2通りの勝ち方の片方。

## 仕上げの日

- **2日目**（不安拡大の事件フェイズ→ターン終了フェイズ）がもっとも強い。学者は不安0でも、不安拡大の2＋暗躍（特性）で完成する。
  主人公の正答は「異世界人への不安−1 で不安拡大を起こさせない」なので、1〜2日目は**異世界人に不安+1 を2日続けて**置き、不安−1 を奪い合う。
- 2日目が止められたら **4日目**（殺人事件で学者に不安6、または不安+1 の積み上げ）。
- それも止められたら **6日目**（最終日）に同じ置き先から2通り: 委員長への暗躍+1（契約）と、移動斜めで委員長を病院へ＋病院に暗躍+1＋ナースに不安+1（病院の事件）。
  暗躍禁止は1日1枚なので両方は止まらない。

## 同時に出す脅威

主人公の1日の守りは、暗躍禁止1枚・不安−1（1ループ1回）・友好能力数回。これを超える組を同じ日に出す。
- 1日目: 委員長に暗躍+2・異世界人に不安+1・学者（または医者）に不安+1。
- 2日目: 異世界人に不安+1・学者に不安+1・委員長に暗躍+1。不安拡大が起きれば学者・委員長の両方が完成に届く。
- 3〜4日目: 学者・医者に不安+1・委員長に暗躍+1（殺人事件を3つ目の脅威に）。

## おとり

- 無関係の**情報屋 C07 に不安禁止**を1〜2日目に置く。主人公の不安−1（1回きり）を空撃ちさせる（readintent に4回当たった。readnulled 以降は学ばれて1回）。
- **ボード（病院・都市）に不安禁止**: 伏せ札を暗躍と決めてかかる主人公の暗躍禁止をボードへずらす（readlook 戦で効いた）。
- **都市に暗躍+1**: ファクターの本物の脅威だが、毎ループ同じ所に置くと不定因子χとファクターを教える（目隠しの Claude の指摘）。日と場所を散らす。
- 少女3人（委員長・異世界人・妹）に暗躍+1 を散らすと、契約のキーパーソンが隠れる。

## 主人公の正答手順への対処

| 主人公の正答 | 脚本家の手 |
|---|---|
| 異世界人に不安−1 で不安拡大を止める | 1日目と2日目に続けて異世界人へ不安+1。不安−1 は1ループ1回なので2日目に通る。おとりで先に使わせる |
| ナースに友好2 → ナース[2]（拒否されない） | ナースに友好が乗りそうな日、とくに能力が要る日（4日目・6日目）の前日に**友好禁止** |
| 学者に友好3 → 学者[3] で自身の全カウンターを除く＋暗躍禁止 | 学者に友好が積まれたら友好禁止。学者[3] の後は特性の暗躍が消えるので、不安と暗躍を同じ日に取り直さない（別の筋へ） |
| 委員長に毎日暗躍禁止 | 1日目に暗躍+2 を吸わせ、以後は委員長への暗躍は不安拡大に任せ、伏せ札は別の負け筋へ |
| 医者・ナースを病院から出す | 殺人事件の組（医者と同じエリアの誰か）を移動先で数え直す |

## 隠す役職

- **ファクター（サラリーマン）**: 最後の戦いで最も外れやすい（defplan3 戦では5人目で外れ）。最終ループまで自殺で勝たない。拒否での割れを防ぐため、サラリーマンへの友好には友好禁止。
- **ラバーズ（ナース）**: 殺人事件でナースを殺すと恋愛風景が一度に割れる。学者の不安を不安+1 と不安拡大だけで作れば、メインラバーズの能力だけを見せられる。
- 委員長（契約）と学者（メインラバーズ）は割れてよい。割れた筋で最短に勝ち、未公開の筋は温存する。

## 勝ちが確定したら

そのループの勝ちが確定したら（例: 1日目の暗躍+2 が通って委員長が暗躍2）、残りの日は押さない。
友好禁止をサラリーマン、暗躍+1 を情報屋（キラーの偽の筋）、不安禁止を刑事へ置いて、何も新しい情報を生まない。事件の効果も情報を生まない人物へ。

## ループごとの方針

- **ループ1（初見）**: 学者の特性は暗躍。1日目に委員長へ暗躍+2・学者へ不安+1・妹へ暗躍+1（少女に散らす）。
  暗躍+2 が通れば契約で確定 → 以後は隠す。止められたら2日目の不安拡大で学者（本命A）。
- **ループ2（契約が割れた後）**: 1日目の暗躍+2 は委員長の暗躍禁止を吸うおとり。異世界人・学者・医者に不安を積み、2日目の不安拡大か4日目の学者で取る。
  都市への暗躍とサラリーマンへの不安を少し混ぜ、「殺人計画かファクターか」を迷わせる。
- **ループ3〜4（契約とメインラバーズが割れた後）**: 主人公は委員長に暗躍禁止・異世界人に不安−1・ナース[2]・学者[3] で守ってくる。
  3つ目の脅威（医者の殺人事件、都市の暗躍）を同じ日に重ね、守りの持ち主に友好禁止。止められそうなら最終日の2通りへ移る。
- **ループ5（最終ループ）**: 隠していた筋（ファクター・病院の事件）も使ってよい。6日目に委員長への暗躍+1 と病院の事件の組を同時に出す。

## 自動の脚本家の指針（d27.json）に落とせなかったこと

- 学者の特性の選択（暗躍に固定）。今は loop_setup が盤面評価で選ぶ（実戦ではほぼ暗躍が選ばれている）。
- 「主人公が友好を積んだ人物に友好禁止」「勝ちが確定したら押さずに隠す」など、盤面の条件で変わる札。json では日を限った小さな加点で近似した。
- 「止められた筋から別の筋へ乗り換える」「前のループで止められた置き場所を避ける」。
- 事件の置き先の条件分け（勝ちが確定したら情報を生まない人物へ）。json では常に同じ優先順。
