## 負け筋（本命・控え）

1. **本命（ループ1）: 時限爆弾（Y_BOMB）** — 1日目に都市へ暗躍+2。ループ終了時の負けで、どの敗北条件かは告げられない。
2. **本命（ループ2〜3）: 遠隔殺人で従者（REMOTE via C12、5日目）** — 1日目に従者へ暗躍+2。異世界人に不安を積んで臨界2に。
3. **控え: 自殺の身代わり（SUICIDE via C03、2日目）** — お嬢様（臨界1）に不安1で自殺。同じ部屋の従者が身代わりに死ぬ。
   教師の能力（ミスリーダー）で1日目にお嬢様へ不安を置けば、札が要らない。
4. **控え: 殺人事件（MURDER via C32、3日目）** — アルバイト（臨界1）に不安1。従者が都市へ逃げてきたら従者、来なければ**守り手の刑事**を殺す。
5. **控え: 行方不明（Y_BOMB via C15、4日目）** — マスコミを都市に留めて都市に暗躍+1。札の暗躍1と合わせて爆弾。

従者を殺す道は3本（自殺の身代わり・殺人事件・遠隔殺人）、主人公の守りは刑事[5] の護衛と異世界人[5] の蘇生の2つしかない。

## 1日目の二択（決め手）

**暗躍+2 と暗躍+1 を別々の負け筋の対象へ**置く。暗躍禁止は1か所しか効かない。
- ループ1: 都市に暗躍+2・神社に暗躍+1・異世界人に不安+1。主人公は神社を塞いで都市が通り、爆弾で確定した。
- ループ2〜3: 従者に暗躍+2・都市に暗躍+1・異世界人に不安+1。都市を塞げば従者が暗躍2（遠隔殺人の標的）、従者を塞げば都市が育つ。

## 仕上げの日

- **1日目**: 二択が通ればその場でループの勝ちが確定（都市2、または従者2＋5日目の遠隔殺人）。
- **2日目**: 自殺の身代わり。教師の能力＋お嬢様への不安+1。
- **3日目**: 殺人事件で守り手（刑事）を消す。
- **5日目**: 遠隔殺人で従者。従者が病院へ逃げていれば、異世界人[5] の蘇生は禁止エリアで届かない。

## おとり

- **神社に暗躍+1**: 幻想の遠隔殺人・封印されしモノに見え、暗躍禁止を吸う（ループ1で5日続けて吸わせた）。
- **異世界人に不安−1**（勝ち確定後）: 不安を打ち消して遠隔殺人を起こさない＝新しい情報を出さない。

## 守り手の消し方

- 刑事（護衛）: 刑事に友好禁止で[5] を遅らせ、3日目の殺人事件の標的にする（ループ3で実行）。
- 異世界人（蘇生）: 従者が病院にいれば届かない。主人公が従者を移動で逃がすときは病院へ行く手を止めない。

## 隠す役職

- **ファクター（お嬢様）**: 一度も表に出さずに済んだ。都市2の状態でお嬢様を死なせる即敗北は最終ループまで使わない（キーパーソンの能力が割れる）。
- **教師＝ミスリーダー**: 教師[4] に友好禁止。お嬢様への不安は教師の能力と札を混ぜて、どちらからか分からなくする。
- **幻想＝フレンド**: 遠隔殺人で幻想を殺すと2人目のフレンドが公開される。標的は従者に絞る。最後の戦いはこれで外れた。
- 割れてよい: ウィッチ（マスコミ[2] の拒否で割れる）、従者のフレンド（死ねば公開）、コピーキャットのミスリーダー。

## 勝ちが確定したら

残りの日は押さない。情報の能力（教師[4]・コピーキャット[3]・刑事[4]）に友好禁止。友好禁止が足りない日は、能力の対象（お嬢様）を移動で引き離す
（主人公の移動と重ねて斜めにする）。神社への暗躍+1（おとり）と異世界人への不安−1 で、何も起きない日を作る。

## ループごとの方針

- **ループ1**: 都市に暗躍+2・神社に暗躍+1（二択）。都市が通れば爆弾で確定 → 2日目から隠す（神社に暗躍+1、刑事・教師に友好禁止、異世界人に不安−1）。
- **ループ2**（爆弾とウィッチを疑われた後。主人公は都市を毎日塞ぐ）: 従者に暗躍+2・都市に暗躍+1。教師の能力でお嬢様に不安、2日目にお嬢様へ不安+1 → 自殺の身代わりで従者。
  教師に友好禁止で[3] を遅らせる。
- **ループ3**（フレンドが割れ、主人公は従者を移動で逃がす）: 1日目は同じ二択。コピーキャットの能力でアルバイトに不安 → 3日目の殺人事件で刑事を消す。
  異世界人に不安+1 を積み、5日目の遠隔殺人で従者（病院に逃げていれば蘇生は届かない）。最終日は友好禁止と移動で情報を隠す。

## 自動の脚本家の指針（d16.json）に落とせなかったこと

- **二択の組**: 「暗躍+2 と暗躍+1 を別々の対象へ」は表せない。対象ごとに札の候補を書いて近似した（_guide_deal は対象ごとに最初に手にある札を当てる）。
- **脚本家の能力（ミスリーダーの不安の置き先）**: 教師→お嬢様（ループ2）、コピーキャット→アルバイト（ループ3）。指針に項目が無い。
- **盤面の条件で変わる札**: 「勝ちが確定したら異世界人に不安−1」「主人公が友好を積んだ人物に友好禁止」「主人公の移動と重ねて斜めに引き離す」。日を限った小さな加点で近似した。
- **事件の置き先の条件分け**: 遠隔殺人でお嬢様を狙うのは都市2のときだけ、殺人事件は従者が都市にいるときだけ従者。json は常に同じ優先順（合法な最初のもの）。
- **ループ単位の筋の重み**: routes の w はループを問わない（爆弾はループ1、遠隔殺人はループ2〜3 の本命）。
- **自殺の身代わりの筋**: エンジンの筋は SUICIDE via C03 を「お嬢様の死（キーパーソン）」として数え、従者の身代わりの死（フレンド）を別の筋として出さない。
